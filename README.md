# Antes de encontrar las palabras — libro digital

## Abrir el libro
1. Descomprimí `libro_agustina_web.zip`.
2. Abrí la carpeta en Visual Studio Code.
3. Abrí `index.html` en el navegador. También podés usar la extensión **Live Server**.

## Qué incluye
- Portada con el título **Antes de encontrar las palabras** y el subtítulo *Un libro para Agustina*.
- Libro visual con páginas enfrentadas en computadora y una página por vez en celular.
- Animación de pasar páginas, índice navegable, contador y barra de progreso.
- Navegación con botones, flechas del teclado y gesto de deslizar en celular.
- Sonido opcional de página, apagado por defecto.
- Diseño adaptable, tonos cálidos, tipografías editoriales y soporte para reducir animaciones.

## Archivos
- `index.html`: estructura, portada y controles.
- `styles.css`: diseño visual, tipografía y animaciones.
- `script.js`: lectura, paginación y navegación.
- `book-content.js`: manuscrito integrado para que el navegador pueda mostrarlo.
- `manuscript.txt`: copia de texto del manuscrito fuente.

## Sobre el texto
El manuscrito se tomó de `Antes de encontrar las palabras.txt`. No se reescribieron sus frases. Para que el libro pueda pasar de página, algunos párrafos extensos se distribuyen visualmente en páginas distintas; las palabras y el orden del manuscrito se mantienen. El libro termina con el texto original «Algo para Joa», sin agregar un epílogo ni una despedida nuevos.

Las tipografías web requieren conexión a internet; sin conexión se usarán fuentes de reserva.
